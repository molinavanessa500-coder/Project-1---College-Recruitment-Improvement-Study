# Project-1---College-Recruitment-Improvement-Study
The overall goal of this project is to, while using Python, perform an exploratory data analysis of the CCM Computing Courses Entry Surveys. This is to help aid the IT department at the County College of Morris increase enrollment in computing classes. At the beginning, I looked over the Majors survey. This survey is administered every Fall semester for entry-level computing classes. I then drafted 5 questions and 'cleaned' the survey data to be easier to use for the questions I wanted answers to. I have uploaded the the 'uncleaned' and 'cleaned' Majors Fall 2026 and my visualizations and data analysis completed by importing matplotlib. This was a great way to showcase the data I have found and made it easier to understand and analyze.
